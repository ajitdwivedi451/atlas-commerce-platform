# Azure Naming Convention

| Resource | Naming Standard | Example |
|----------|-----------------|---------|
| Resource Group | rg-<project>-<env>-<region> | rg-atlas-dev-eastus |
| Storage Account | st<project><env><number> | statlasdev002 |
| Azure Data Factory | adf-<project>-<env> | adf-atlas-dev1 |
| Databricks Workspace | dbw-<project>-<env> | dbw-atlas-dev |
| Databricks compute | cluster-<project>-<env> | cluster-atlas-dev |
| Key Vault | kv-<project>-<env> | kv-atlas-dev1 |
| Event Hub Namespace | eh-<project>-<env> | eh-atlas-dev |
| Synapse Workspace | syn-<project>-<env> | syn-atlas-dev |
| Log Analytics | log-<project>-<env> | log-atlas-dev |
